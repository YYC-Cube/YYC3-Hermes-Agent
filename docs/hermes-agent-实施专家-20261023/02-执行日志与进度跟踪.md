### 2026-10-23 03:35 - 故障定位：CDN 拒绝 1 字节 Range

**操作类型**：根因分析（只读）

**复现与结论**：

- `urllib` 请求 `Range: bytes=0-0` → GitHub release-assets 返回 **400**
- `Range: bytes=0-1048575`（1MB）→ **206**
- `uv 0.12.3` 资产即使普通 GET 也返回 **400**；但 Nous 镜像同 sha256 返回 **200**
- 结论：不是资产损坏，而是源站对探测请求的拒绝；pm 的 `DownloadTransportError.fallback_allowed` 不含 400，导致不会回退到镜像

**当前状态**：✅ 定位完成

- 缓解：不可信任务使用 `docker` / `ssh` 沙箱后端；不运行来源不明的技能；必要时在启动 shell 前清理相关环境变量。

### 本地自用建议

1. **主模型已本地化**：当前使用 Ollama `qwen3-coder-30b-64k`，对话与辅助任务均不出本机；保持 Ollama 运行即可。若需更强能力，登录云端 provider 后再切回。
2. **辅助模型本地化**：把 `auxiliary.compression` / `vision` / `title` 固定到本地端点，避免压缩摘要外发。
3. **不需要联网检索时**：设 `web.keyless_fallback=false`，并从工具集移除 `web_search` / `web_extract`。
4. **浏览器保持本地**：不配置 `browser.cdp_url`，不使用 Browserbase；不浏览时禁用 `browser_*`。
5. **记忆保持内置**：不要配置外部 memory provider。
6. **不要随意运行 `hermes doctor --live`**：它会对已配置的工具后端发起真实外部调用。
7. **网关按需启动**：启动时确认绑定 `127.0.0.1` 并设置访问策略。
