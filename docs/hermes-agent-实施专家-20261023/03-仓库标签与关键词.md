## 四、使用建议

1. **Topics**：在仓库首页 `About` → `Topics` 中粘贴上述 20 个，GitHub 上限即 20 个。
2. **Description**：优先使用英文短描述；中文描述可放在 README 首段或 About 的第二行。
3. **README 关键词**：在 README 首段自然出现 `self-improving`、`local-first`、`Ollama`、`MCP`、`multi-channel`，不要堆砌。
4. **Release 标签**：建议沿用 `vYYYY.MM.DD` 或语义化版本，与现有 `v2026.9.14` 风格保持一致。

## 五、标签维护

| 场景 | 建议 |

| 新增平台适配器 | 增加对应 `*-bot` topic，总数不超过 20 |
