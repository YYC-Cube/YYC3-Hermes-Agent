## 三、fork Pages 自动部署

上游 `deploy-site.yml` 被 `github.repository == 'NousResearch/hermes-agent'` 门控（GitHub App token + skills 爬取），fork 完全不可复用。新建 [deploy-pages.yml](../../.github/workflows/deploy-pages.yml)：

- **零凭据**：仅 `GITHUB_TOKEN` + `permissions: pages: write, id-token: write`
- **skills-index 复用**：live CDN GET `hermes-agent.nousresearch.com/docs/api/skills-index.json`，失败兜底 `{"skills": []}`（文档站不因上游 API 波动而阻塞）
- **自定义域**：`pubilc/CNAME`（agent.yyc3.vip）staged 到 artifact 根部
- **根路径部署**：`baseUrl /docs/` → `/`，staging 根平铺（`_site/` 直出）
- **门控**：`github.repository == 'YYC-Cube/YYC3-Hermes-Agent'`；触发 = push main（`website/**` / `pubilc/**` / workflow 自身）+ `workflow_dispatch`
- 所有 action 均 SHA pin + 版本注释（仓库 Pinning Policy）

**首跑失败与闭环修复**（run 39906657997 → `fix(deps)` commit → run 39907204550 SUCCESS）：

- 根因：本地全局 npm registry 为 npmmirror，`npm install` 把镜像 tarball URL 写入 lockfile（根 44 + website 12 处）；GitHub Actions 的 npm ≥ 11.6 将非配置 registry host 的包判为 remote 类型，`EALLOWREMOTE` 拒绝获取
- 修复：两个 lockfile host 替换 `registry.npmmirror.com` → `registry.npmjs.org`（integrity 不变），经验写入部署指南「Keep lockfiles on the official registry」提示框
- **部署成功实测**：HTTP/2 200 @ agent.yyc3.vip，`CNAME` 内容正确，DNS 解析 `yyc-cube.github.io` + Pages 四 IP，上游 Deploy Site 门控 `skipped` 符合预期

**域名迁移注记**（当日后续批次）：用户将 `pubilc/CNAME` 变更为 `h-agent.yyc3.vip`，全局引用同步完成——四 README nav 与 Docs 徽章（shields 标签转义 `h--agent.yyc3.vip`）、`docusaurus.config.ts url`、workflow 注释、部署指南、repo homepage（`gh api PATCH` 已生效）。本节上文 `agent.yyc3.vip` 字样为该批次当时实测记录，保留不回写。DNS 已验证解析至 Pages；专属证书随新域名重新签发。

**落地页架构注记**（2026-10-24）：站点根 `/` 由 `pubilc/YYC3-HERMES-HUB-OFFLINE.html`（单文件零依赖操作中心）在 staging 阶段覆写接管；Docusaurus 文档总览页由 `slug: /` 迁移至 `slug: /docs`（en 与 zh-Hans 双份同步）。`baseUrl`、`routeBasePath`、既有重定向与文档 URL 全部不变，仅根入口换面。以上文的「URL shape → Domain root」描述仍成立，文档树根由 `/` 改为 `/docs`。

### 4.2 图标全端接线

源：`pubilc/yyc3-icons/`（iOS / Android / macOS / Windows / tvOS / watchOS 全集）

```
macos/AppIcon.iconset ──iconutil──▶ apps/desktop/assets/icon.icns
windows/icon-256.png ──Pillow──▶ apps/desktop/assets/icon.ico   (6 帧 16–256)
                     ─────────▶ web/public/favicon.ico
                     ─────────▶ website/static/img/favicon.ico
macos/icon_512x512@2x ─────────▶ icon.png / apple-touch-icon.png / logo.png
```

**Bug 修复**：Pillow 对 ICO 的 `append_images` 参数无效（仅写出 16x16 单帧），正确 API 为 `save(format='ICO', sizes=[(16,16)...(256,256)])`——Pillow 从源图自行缩放生成各帧。

**刻意不动**：桌面端 `productName: Hermes` / `appId: com.nousresearch.hermes` / 协议处理器——自动更新链与 deep link 依赖此身份，属运行时契约而非展示品牌。
