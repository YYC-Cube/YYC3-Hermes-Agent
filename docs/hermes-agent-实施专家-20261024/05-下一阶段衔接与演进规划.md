## 二、节点规划

### M4 · P0-5 收口：线上安全头（前置：用户切 NS）

**步骤**（详见 [04 手册](./04-P0-5线上安全头执行手册.md) 第七节）：

```bash
# 0) 推送五提交 → CI 自动 Pages 部署（分片目录 + HUB CSP meta 随之上线）
git push origin main
# 1) 首次接入（zone 不在 CF）：创建 zone，打印应设 NS
export CF_API_TOKEN='***'
bash docs/hermes-agent-实施专家-20261024/scripts/p05-cloudflare-configure.sh --apply --add-zone --account-id <ID>
# 2) 用户在阿里云控制台把 NS 改为上一步打印值，等待 zone active
# 3) dry-run 核对 → 应用
bash docs/hermes-agent-实施专家-20261024/scripts/p05-cloudflare-configure.sh
bash docs/hermes-agent-实施专家-20261024/scripts/p05-cloudflare-configure.sh --apply
```

**验收**：`curl -I` 可见 5 类头 + `server: cloudflare`；首页、`/docs/`、`/api/skills.json` 均 200；搜索与图片无 CSP 报错。
**回滚**：手册第四节（规则禁用 / 灰色云）。
**责任**：步骤 2 仅用户可操作；其余 AI 可代执行。
