## 二、节点规划

### M4 · P0-5 收口：线上安全头（✅ 路径已定：方案 B 子域级 CNAME 接入）

**决策（2026-10-24）**：`yyc3.vip` 挂 70+ 项目子域，用户选定**方案 B——子域级 CNAME 接入阿里云 DCDN 海外区域**，不动整区 NS；Cloudflare 路径（`p05-cloudflare-configure.sh`）保留为备选。

**步骤**（用户控制台操作，见 [04 手册第八节](./04-P0-5线上安全头执行手册.md)）：
1. 开通 DCDN → 添加 `h-agent.yyc3.vip`（源站 `yyc-cube.github.io`，仅海外）→ TXT 验证；
2. 免费证书 + 强制 HTTPS；确认回源 Host = 加速域名；
3. 自定义响应头 5 类；云解析把 `h-agent` CNAME 改指 DCDN 值（回滚点）；
4. curl 验收（AI 代执行）。

**验收**：5 类头 + `server` 非 `GitHub.com` + 三 URL 200。
**回滚**：CNAME 改回 `yyc-cube.github.io`，分钟级生效。
