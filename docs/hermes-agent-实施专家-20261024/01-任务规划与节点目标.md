# 任务规划与节点目标

## 规划总则

> 执行有规划，规划有节点，节点有目标，目标可评估。

本轮目标不是“继续加功能”，而是把本地自用链路做成**可复现、可验证、可交接**的生产闭环，并用真实数值证明修复有效。

## 一、总体目标

| 目标 | 验收口径 |
| --- | --- |
| 运行时与锁文件一致 | venv 包版本与 `uv.lock` 偏差 = 0；OSV = 0 |
| 依赖漏洞归零 | 锁文件与运行时 critical/high = 0 |
| 安全补丁对齐 | 上游 0.21.6 的 4 个 Dashboard 认证问题全部 backport，定向测试通过 |
| 本地测试可解释 | 搜索类失败归零；剩余失败可按环境/平台归因 |
| 站点首屏可接受 | 技能目录首屏 ≤ 5 MB；统一索引不再发布 |
| 文档可交接 | 00/01/02/03 + JSONL 日志齐全，含快速恢复命令 |

## 二、阶段划分

| 阶段 | 名称 | 目标 | 状态 |
| --- | --- | --- | --- |
| P0 | 可复现基线 | uv/venv/brotli/上游安全补丁 | ✅ 代码完成；线上头待 Cloudflare |
| P1 | 可持续交付 | ripgrep、技能索引、doctor、回归验证 | ✅ 完成 |
| P2 | 智能化演进 | SBOM、类型门禁、0.22 评估、供应链签名 | ⏳ 未开始 |

## 三、任务分解

### P0-1 运行时对齐

- **目标**：`uv sync --locked` 产出与锁文件一致的 venv。
- **动作**：uv 0.9.7 → 0.13.5；`uv sync --locked --active --extra all --extra dev`；清理 18 个非选装残留包。
- **验收**：109 包、0 版本偏差、0 OSV。
- **状态**：✅ 完成。

### P0-2 brotlicffi 修复

- **目标**：关闭 GHSA-9v8h-qqgm-4m35。
- **动作**：`pyproject.toml` / `tools/lazy_deps.py` / `uv.lock` 升至 `1.2.1.0`。
- **验收**：锁文件 259 包 OSV = 0。
- **状态**：✅ 完成。

### P0-3 工具链

- **目标**：本地 uv 能解析锁文件，且与 CI 口径兼容。
- **动作**：Homebrew 升级 uv 0.13.5；用独立 uv 0.9.28 验证 `uv sync --locked`。
- **验收**：无 TOML 解析错误；锁可被 CI 版本读取。
- **状态**：✅ 完成。

### P0-4 Dashboard 认证安全 backport

- **目标**：落地上游 0.21.6 的 4 个 Tenable 问题。
- **动作**：
  - #133367：`client_ip()` 只取 ASGI peer，忽略伪造 `X-Forwarded-For`。
  - #133369：`provider` 限长 128；审计日志所有字段限长 256。
  - #133370：公开 `/auth/` POST 64 KiB body limit（ASGI 中间件）。
  - #130685：原生登录 redirect_uri 只接受规范 loopback authority。
  - #133865（同族加固）：密码登录限流桶上限 4096，过期桶先清理。
- **验收**：4 个定向测试文件 56 通过；9 个 dashboard-auth 回归文件 138 通过。
- **状态**：✅ 代码完成；上游 0.22 结构重构不在本轮。

### P0-5 线上安全头

- **目标**：HSTS/CSP/XFO/XCTO/Referrer-Policy 上线。
- **动作**：HUB 已加 CSP + Referrer meta；仓库侧无法改 DNS/CDN。
- **进展（第二会话）**：确认 `yyc3.vip` NS 在阿里云 `dns29/dns30.hichina.com`（Cloudflare 无 zone）；已交付幂等脚本 `scripts/p05-cloudflare-configure.sh`（dry-run 默认 / `--apply` / `--add-zone` / `--with-csp-report-only`），把手册第二节 Dashboard 步骤固化为 API 调用。
- **阻塞**：注册商 NS 切换仅用户可操作；本机无 Cloudflare Token。
- **状态**：◐ 部分完成，脚本就绪；待用户切 NS + 提供 Token 后一条命令闭环。

### P1-1 ripgrep

- **目标**：本地 rg 与 CI 对齐，消除搜索类失败。
- **动作**：14.1.1 → 15.2.0；修复 `killpg` 的 `PermissionError` 兜底。
- **验收**：5 个搜索文件隔离运行 **49/49 通过**；全量 32 并发下 18 个搜索类失败归因为测试隔离，非 rg 回归。
- **状态**：✅ 完成（隔离验证通过；并发隔离留 P2）。

### P1-2 技能索引拆分

- **目标**：首屏不再下载 56 MB `skills.json`，统一索引不再发布。
- **动作**：按 source 分片；core 2,285 技能 / 1.6 MB；ClawHub 45 MB、skills.sh 9.5 MB 按需加载；索引移至 `website/.cache/`。
- **验收**：`npm run build` 成功；`build/api` 无 `skills-index.json`；meta 含 shards。
- **状态**：✅ 完成。

### P1-3 doctor 建议

- **目标**：不再建议 `pip install -e '.[all]'`。
- **动作**：改为 `uv sync --locked --extra all`，并说明 venv 无 pip。
- **验收**：`test_doctor_command_install.py` 3/3 通过；`hermes doctor` 输出新建议。
- **状态**：✅ 完成。

## 五、依赖与风险

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 无 Cloudflare 权限 | P0-5 无法验收 | 提供 Transform Rules 与 curl 验收脚本；申请最小 API Token |
| 上游 0.22 结构重构 | 直接 rebase 风险高 | 先 0.21.7 安全补丁，再分阶段合并 |

| 平台测试差异 | 本地不是 CI 等价环境 | 补 macOS marker；CI 继续用 OS 矩阵 |
