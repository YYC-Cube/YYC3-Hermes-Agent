## 八、Pages 发布失效与自愈（2026-11-18）

- **症状**：`h-agent.yyc3.vip/` 与 `/docs/` 返回 404；**直连 GitHub Pages 源站同样 404（连 `/CNAME` 都 404）**，排除 DCDN。
- **根因**：Pages 侧发布内容失效（部署记录 11-11 为 success，但源站无内容）；`deploy-pages.yml` 仅由 `website/**`、`pubilc/**`、工作流自身变更触发——近期合并均为 docs/code/deps，**无人重发**，故障长期潜伏。
- **处置**：`gh workflow run deploy-pages.yml` → success → `/`、`/docs/`、`/skills/`、`/zh-Hans/docs/`、`/api/skills-meta.json`、`/llms.txt` 全部 **200**。
- **加固**（`scripts/yyc3-maintenance.sh` 第 3 步）：
  1. 探测 **3×5s 重试**，避免 DCDN 瞬时抖动（000）误判；
  2. 仍非 200 → **自动重发 Pages 部署**，最多等 6 分钟并复测（自愈）；
  3. 分片 JSON 探测同样 3 次重试（重部署后边缘缓存瞬时未就绪曾报 0 片）；
  4. 顺手修两个潜伏 bug：`$CERT（` 全角括号被 bash 吞进变量名（仅证书缺失分支触发）；证书路径回退到 `~/.yyc3-keybackup/.lego/certificates/`（`~/.lego` 已不存在，实测余 69 天）。
